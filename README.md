# pairwise-skinning-dq

角色做大幅度扭腰，肩部网格塌陷成尖角，武器挂点又滑出掌心：蒙皮只用线性混合，两个骨骼夹角大时出现糖果纸塌陷；双四元数没有归一化，缩放和剪切混进旋转；骨骼调色板按骨骼索引排列，换 LOD 后索引错位；根运动在蒙皮前应用，角色位移被算两次；GPU 蒙皮和 CPU 碰撞用两套骨骼，武器位置对不上；混合形状在蒙皮后叠加，表情把头部网格拉裂；双四元数对非均匀缩放处理错误，角色变胖后关节鼓包；骨骼更新异步读上一帧，快速转身时肩部滞后；LOD 切换时骨骼数不同，权重映射没有重采样；约束求解在蒙皮后做，扭转修正看不到；蒙皮缓存按网格 ID，换皮肤后仍用旧权重；多角色共用骨骼纹理，批次间骨骼槽位串；法线蒙皮只做旋转，缩放后光照方向错。render/skinning_dq.py 是核心，tests/test_skinning_dq.py 15个红。要修的是：双四元数；归一化；LOD 调色板；根运动顺序；GPU/CPU 一致；混合形状顺序；非均匀缩放；异步骨骼；权重重采样；约束顺序；缓存版本；骨骼槽位；法线缩放。

## 运行

```bash
python -m pytest tests -q
```

初始状态：15 个用例失败。修复实现使全部用例通过，不要修改 `tests/` 下的测试。
